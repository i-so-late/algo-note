# algo-note

Personal notes and solutions for algorithm problems, mostly from LeetCode.

## Structure

- `L<number>. <Title>.<ext>`: solution to a LeetCode problem, e.g. `L377. Combination Sum IV.cpp`
- `Atemplate.cpp`: starting template for new C++ solutions
- `data_structures/`: reusable implementations of common data structures

## Languages

Mainly C++

## Usage

Each solution is a standalone file. To run a C++ solution:

    g++ -std=c++17 "L377. Combination Sum IV.cpp" -o sol && ./sol
